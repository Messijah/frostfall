# Frostfall

Support and privacy pages for Frostfall, a living winter on your Mac desktop.

- Support: https://messijah.github.io/frostfall/
- Privacy policy: https://messijah.github.io/frostfall/privacy.html

Questions and problems go in [Issues](https://github.com/Messijah/frostfall/issues). Please say which Mac and macOS version you use and what happened. Everything written there is public, so do not include personal details.

På svenska: frågor och fel skrivs under [Issues](https://github.com/Messijah/frostfall/issues). Allt som skrivs där syns för alla, så skriv inga personuppgifter.
